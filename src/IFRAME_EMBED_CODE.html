1. Basic Embed Code (Recommended)

Use this code to embed the map with a fixed height that works across all screen sizes.

<iframe src="https://npsportal.app/CCWReciprocityMap" width="100%" height="750px" frameborder="0" style="border:none;display:block;" title="CCW Reciprocity Map — Nationwide Police Services" loading="lazy"> </iframe>

Parameters Explained:

src: The public URL to the CCW map (replace https://npsportal.app with your actual domain)
width="100%": Makes the iframe fill the full width of its container
height="750px": Sets a fixed height. Adjust this value based on your design needs
loading="lazy": Defers loading the iframe until it's about to enter the viewport (improves page speed)

2. Responsive Embed Code (For Flexible Sizing)

Use this code if you want the iframe to maintain a specific aspect ratio on all screen sizes.

<div style="position: relative; width: 100%; padding-bottom: 56.25%;"> <iframe src="https://npsportal.app/CCWReciprocityMap" width="100%" height="100%" style="position: absolute; top: 0; left: 0; border: none;" frameborder="0" title="CCW Reciprocity Map — Nationwide Police Services" loading="lazy"> </iframe> </div>

This Method:

✓ Maintains a 16:9 aspect ratio on all devices
✓ Automatically scales width while keeping proportions
✓ Change 56.25% to 75% for 4:3 aspect ratio

6. Troubleshooting

Map Not Loading?

✓ Verify the domain URL is correct
✓ Check that your domain allows iframe embedding (no X-Frame-Options: DENY header)
✓ Ensure HTTPS is used on both your website and the iframe source

Map Appears Cut Off?

✓ Increase the height value (e.g., 800px instead of 750px)
✓ Use the responsive embed code (Option 2) for better scaling

Mobile Responsiveness Issues?

✓ Use the responsive embed code that maintains aspect ratio
✓ Test on multiple devices (phone, tablet, desktop)
